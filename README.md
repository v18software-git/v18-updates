# V18 Updates

This repository hosts the public update manifest and GitHub Release files for V18 app updates.

## Files

- `latest-version.json` - app update manifest read by the V18 app.
- GitHub Releases - upload Windows `.zip` and Android `.apk` builds here.

## Current App Manifest URL

```text
https://raw.githubusercontent.com/V18PreniumTuition/v18-updates/refs/heads/main/latest-version.json
```

Keep the repository owner/name as `V18PreniumTuition/v18-updates` if you do not want to change the app config.
